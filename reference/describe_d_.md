# Show Discriptive statistics for categorical variables. The output is formatted with `gt` so that you can easily include it in Rmarkdown documents.

Show Discriptive statistics for categorical variables. The output is
formatted with `gt` so that you can easily include it in Rmarkdown
documents.

## Usage

``` r
describe_d_(.data, ...)
```

## Arguments

- .data:

  input a tibble or data.frame

- ...:

  categorical variables
