# format a result of latent class analysis with `poLCA_result`

format a result of latent class analysis with `poLCA_result`

## Usage

``` r
poLCA_check_class(.poLCA_result_table, nclass)
```

## Arguments

- .poLCA_result_table:

  an object exported from
  [`poLCA_result()`](https://kentaro-kamada.github.io/kamaken/reference/poLCA_result.md)

- nclass:

  number of latent classes to check class property
